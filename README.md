## ฟีเจอร์ตามวัตถุประสงค์ 5 ข้อ
1. Zero Packing Errors: สแกนแล้วแสดงชื่อสินค้าตัวโต ตัวเลือก/สีพร้อมวงสี จำนวน ×N (ถ้ามากกว่า 1 ชิ้นจะเป็นสีแดง) รองรับหลายสินค้าต่อออเดอร์ มีหมายเหตุลูกค้า เตือนเมื่อสแกนซ้ำ และเตือนเมื่อเลขไม่อยู่ในไฟล์ออเดอร์
2. Zero Cross-Loading: โหมดตรวจเช็คขึ้นรถ ถ้าถูกคันจะขึ้นจอเขียว ถ้าผิดคันจะขึ้นจอแดงกระพริบ มีไซเรน สั่น และเสียงพูดไทย ถ้ายังไม่ได้แพ็คหรือส่งมอบไปแล้วจะเตือนสีเหลือง
3. Courier Handover: ตัดรอบส่งมอบแยกตามขนส่ง เทียบกับยอดที่คนขับนับ มีรูปท้ายรถพร้อมลายน้ำเวลา กล่องที่ค้างจะยกไปรอบถัดไป และส่งเข้า LINE ได้
4. Zero-Install: กล้องหลัง + ปืนยิงบาร์โค้ด USB/Bluetooth + โหมดถ่ายรูป (บาร์โค้ด → OCR) + พิมพ์เลขเอง
5. Big Tag: พิมพ์ป้าย A5 แนวนอน ตัวอักษรใหญ่ ได้ทีละใบหรือทั้งวัน

## v2 (20 ต.ค. 2026): ตัวอ่านบาร์โค้ดใหม่
- เปลี่ยนจาก html5-qrcode เป็น BarcodeDetector ของเครื่อง (Android) และใช้ barcode-detector@3.2.2 (ZXing-C++ WASM) สำหรับ iPhone
- กล้องเปิดที่ 1920×1080 แล้วสแกนสลับหลายแบบ ถ้าเจอหลายบาร์โค้ดจะเลือกเลขพัสดุก่อน ค้นหาด้วยเลขออเดอร์ได้ และแสดงที่อยู่เต็ม
- ถ้าเลขไม่อยู่ในไฟล์ จะอธิบายว่าต้องโหลดไฟล์ออเดอร์ก่อน

## v2.1 (20 ต.ค. 2026): แก้บาร์โค้ดแท่ง SPX อ่านไม่ได้
- สาเหตุ: ใบปะหน้า SPX มีกล่องดำ "MP" ติดชิดหัวบาร์โค้ด จึงไม่มี quiet zone ทำให้ ZXing หาจุดเริ่มไม่เจอ (ยืนยันจากรูปใบปะหน้าจริง: ทาสีด้านซ้ายแล้วอ่านได้)
- แก้ด้วย fixQuietZones(): หาช่วงลายบาร์โค้ดทีละแถวด้วย threshold แบบ global ร่วมกับ local โดยใช้แถวที่มีกล่องดำอยู่ชิดซ้ายเป็นหลักฐานของขอบซ้าย แล้วทาฝั่งซ้ายด้วย "สีพื้นกระดาษ" ไม่ใช่สีขาวล้วน (ขาวล้วนทำให้ threshold ของ ZXing เพี้ยน จนอ่านไม่ได้)
- ใช้ในกล้องสด (สลับ 4 แบบ: ทั้งภาพ / ครอป+ซ่อม / ครอป / ครอปแคบขยาย+ซ่อม) และในโหมดถ่ายรูป
- ผลทดสอบกับรูปจริง: SPX TH2659775850320 และ TH261685034517U อ่านได้ทั้งภาพนิ่งและกล้องจำลอง ส่วน DHL 7127106028255256 อ่านได้
- QR บนใบ SPX/DHL เข้ารหัสเลขพัสดุเหมือนบาร์โค้ดแท่ง
- เพิ่มรูปแบบเดาขนส่ง DHL: เลข 16 หลักที่ขึ้นต้นด้วย 71

## อื่นๆ
- นำเข้า Excel/CSV หลายไฟล์ จับคอลัมน์ Shopee / TikTok / Lazada ให้อัตโนมัติ
- รายงานรายวันดูย้อนหลังได้ 60 วัน ส่งออก CSV หรือส่ง LINE ได้ เก็บรูปส่งมอบ 7 วัน

## ข้อจำกัด / งานต่อ
- ข้อมูลแยกกันในแต่ละเครื่อง แต่ละเครื่องต้องโหลด Excel เอง (งานต่อ: ซิงก์ผ่าน Google Sheets)

- กล้องสดใช้ได้เฉพาะ HTTPS ใน Safari/Chrome
