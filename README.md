# PackScan Pro (Hybrid): บันทึกการพัฒนา (20 ต.ค. 2026)

ไฟล์เดียว index.html (HTML+JS inline) แทน index.html + app.js เดิม และเก็บข้อมูลใน localStorage ของเครื่อง

## ฟีเจอร์ตามวัตถุประสงค์ 5 ข้อ
1. Zero Packing Errors: สแกนแล้วแสดงชื่อสินค้าตัวโต ตัวเลือก/สีพร้อมวงสี จำนวน ×N (ถ้ามากกว่า 1 ชิ้นจะเป็นสีแดง) รองรับหลายสินค้าต่อออเดอร์ มีหมายเหตุลูกค้า เตือนเมื่อสแกนซ้ำ และเตือนเมื่อเลขไม่อยู่ในไฟล์ออเดอร์
2. Zero Cross-Loading: โหมดตรวจเช็คขึ้นรถ ถ้าถูกคันจะขึ้นจอเขียว ถ้าผิดคันจะขึ้นจอแดงกระพริบ มีไซเรน (WebAudio) สั่น และเสียงพูดไทย ถ้ายังไม่ได้แพ็คหรือส่งมอบไปแล้วจะเตือนสีเหลือง มีตัวนับ ขึ้นรถแล้ว/แพ็คแล้ว และรายการกล่องที่ค้าง
3. Courier Handover: ตัดรอบส่งมอบแยกตามขนส่ง เทียบกับยอดที่คนขับนับ มีรูปท้ายรถพร้อมลายน้ำเวลา กล่องที่ค้างจะยกไปรอบถัดไป และส่งเข้า LINE ผ่าน Web Share (แนบรูปได้) หรือลิงก์ line.me
4. Zero-Install: ใช้กล้องหลังผ่าน html5-qrcode รองรับปืนยิงบาร์โค้ด USB/Bluetooth (keyboard wedge) ได้ทุกหน้าจอ มีโหมดถ่ายรูปที่อ่านบาร์โค้ดก่อน แล้วค่อยใช้ OCR (โหลด Tesseract เฉพาะตอนใช้) และพิมพ์เลขเองได้
5. Big Tag: พิมพ์ป้าย A5 แนวนอน ตัวอักษรใหญ่ (ขนส่ง/สินค้า/สี/จำนวน/ปลายทาง) ได้ทีละใบหรือทั้งวัน

## อื่นๆ
- นำเข้า Excel/CSV ได้หลายไฟล์ ระบบจับคอลัมน์ไทย/อังกฤษของ Shopee / TikTok / Lazada ให้อัตโนมัติ และรวมสินค้าที่เลขพัสดุเดียวกัน
- ถ้าไม่มีในไฟล์ จะเดาขนส่งจากรูปแบบเลขพัสดุแทน (ไฟล์ออเดอร์แม่นกว่า)
- รายงานรายวันดูย้อนหลังได้ 60 วัน แยกตามแพลตฟอร์ม/ขนส่ง (แพ็ค/ขึ้นรถ/ส่งมอบ) มีสินค้าขายดี และออเดอร์ที่ยังไม่แพ็ค ส่งออกเป็น CSV (UTF-8 BOM) หรือส่งข้อความเข้า LINE ได้
- เก็บรูปส่งมอบไว้ 7 วัน
- มีปุ่ม "โหลดข้อมูลทดลอง" สำหรับเดโม

## ข้อจำกัด / งานต่อ
- ข้อมูลอยู่แยกกันในแต่ละเครื่อง ยังไม่ซิงก์ข้ามเครื่อง (ต่อไปอาจทำ Google Sheets / backend)
- กฎเดาขนส่งจากเลขพัสดุเป็นแค่ค่าประมาณ ควรใช้ไฟล์ออเดอร์เป็นหลัก
- กล้องสดใช้ได้เฉพาะ HTTPS
