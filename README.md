## ฟีเจอร์ตามวัตถุประสงค์ 5 ข้อ
1. Zero Packing Errors: สแกนแล้วแสดงชื่อสินค้าตัวโต ตัวเลือก/สีพร้อมวงสี จำนวน ×N (ถ้ามากกว่า 1 ชิ้นจะเป็นสีแดง) รองรับหลายสินค้าต่อออเดอร์ มีหมายเหตุลูกค้า เตือนเมื่อสแกนซ้ำ และเตือนเมื่อเลขไม่อยู่ในไฟล์ออเดอร์
2. Zero Cross-Loading: โหมดตรวจเช็คขึ้นรถ ถ้าถูกคันจะขึ้นจอเขียว ถ้าผิดคันจะขึ้นจอแดงกระพริบ มีไซเรน สั่น และเสียงพูดไทย ถ้ายังไม่ได้แพ็คหรือส่งมอบไปแล้วจะเตือนสีเหลือง
3. Courier Handover: ตัดรอบส่งมอบแยกตามขนส่ง เทียบกับยอดที่คนขับนับ มีรูปท้ายรถพร้อมลายน้ำเวลา กล่องที่ค้างจะยกไปรอบถัดไป และส่งเข้า LINE ได้
4. Zero-Install: กล้องหลัง + ปืนยิงบาร์โค้ด USB/Bluetooth + โหมดถ่ายรูป (บาร์โค้ด → OCR) + พิมพ์เลขเอง
5. Big Tag: พิมพ์ป้าย A5 แนวนอน ตัวอักษรใหญ่ ได้ทีละใบหรือทั้งวัน

## v2 (20 ต.ค. 2026): ตัวอ่านบาร์โค้ดใหม่
- เปลี่ยนจาก html5-qrcode เป็น BarcodeDetector ของเครื่อง (Android) และใช้ barcode-detector@3.2.2 (ZXing-C++ WASM) สำหรับ iPhone
- กล้องเปิดที่ 1920×1080 แล้วสแกนสลับหลายแบบ ถ้าเจอหลายบาร์โค้ดจะเลือกเลขพัสดุก่อน ค้นหาด้วยเลขออเดอร์ได้ และแสดงที่อยู่เต็ม

## v2.1 (20 ต.ค. 2026): แก้บาร์โค้ดแท่ง SPX อ่านไม่ได้
- สาเหตุ: ใบปะหน้า SPX มีกล่องดำ "MP" ติดชิดหัวบาร์โค้ด จึงไม่มี quiet zone (ยืนยันจากรูปใบปะหน้าจริง)
- แก้ด้วย fixQuietZones(): หาช่วงลายบาร์โค้ด แล้วทาฝั่งซ้ายด้วย "สีพื้นกระดาษ" ไม่ใช่สีขาวล้วน (ขาวล้วนทำให้ threshold ของ ZXing เพี้ยน)
- ผลทดสอบกับรูปจริง: SPX TH2659775850320 / TH261685034517U และ DHL 7127106028255256 อ่านได้
- QR บนใบ SPX/DHL เข้ารหัสเลขพัสดุเหมือนบาร์โค้ดแท่ง และเดาว่าเป็น DHL เมื่อเป็นเลข 16 หลักที่ขึ้นต้นด้วย 71

## v2.2 (20 ต.ค. 2026): นำเข้าไฟล์ออเดอร์ได้ทุกรูปแบบ
- ปัญหาที่พบ: ไฟล์จริงของผู้ใช้ (SPX10.10.26_2, DHL14.10.26_1, Tiktok 16.10.69 _1, Lazada 16.10.69) ไม่ใช่รูปแบบ export มาตรฐาน ทำให้ระบบไม่เจอชื่อสินค้า หรือไม่เจอคอลัมน์เลขพัสดุ
- หาแถวหัวตารางได้เองในช่วง 30 แถวแรก (กรณีไฟล์มีหัวรายงานอยู่ด้านบน)
- ถ้าไม่มีหัวคอลัมน์เลขพัสดุ จะดูจากค่าในคอลัมน์ว่าคอลัมน์ไหนมีรูปแบบเป็นเลขพัสดุ
- อ่านคอลัมน์ product_info / ข้อมูลสินค้า ของ Shopee ที่รวมหลายสินค้าใน 1 ช่อง ("[1] ชื่อสินค้า:...; ชื่อตัวเลือก:...; จำนวน: n")
- ถ้าจับคอลัมน์ไม่ครบ (ไม่มีเลขพัสดุ หรือไม่มีชื่อสินค้า) จะเปิดหน้าต่างให้เลือกคอลัมน์ 1 ครั้ง พร้อมตัวอย่างข้อมูล แล้วจำไว้ตามชื่อไฟล์ (ตัดตัวเลขออก) + หัวคอลัมน์ ไฟล์วันถัดไปจึงนำเข้าเองอัตโนมัติ ล้างค่าที่จำไว้ได้ในหน้าตั้งค่า
- ระบุขนส่งตามลำดับ: คอลัมน์ขนส่ง → รูปแบบเลขพัสดุ → ชื่อไฟล์ (SPX/DHL/Flash...)
- ผลนำเข้าแสดงจำนวนแยกตามขนส่งของแต่ละไฟล์ และเตือนถ้าไฟล์ไม่มีชื่อสินค้า รายการออเดอร์แสดงชื่อไฟล์ที่มา และมีป้ายนับแยกขนส่ง
