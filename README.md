# 📦 PackScan Pro (Hybrid)

ระบบสแกนตรวจสอบการแพ็คและคัดแยกส่งมอบขนส่ง E-Commerce ของ **เพชรสยาม (PST)**

- **เปิดใช้งาน:** https://thesor55.github.io/packscan/
- **เวอร์ชันปัจจุบัน:** v2.3.1 (ดูเลขเวอร์ชันได้ที่หัวแอป ข้างคำว่า "Hybrid")
- **รูปแบบ:** Web App ไฟล์เดียว (`index.html`) ไม่ต้องติดตั้ง ใช้ได้กับ iPhone (Safari), Android (Chrome) และโน้ตบุ๊ก/PC

---

## 🎯 วัตถุประสงค์

| # | เป้าหมาย | ระบบช่วยอย่างไร |
|---|---|---|
| 1 | **แพ็คไม่ผิดรุ่น/สี/จำนวน** | สแกนแล้วแสดงชื่อสินค้าตัวใหญ่ สีพร้อมวงสีจริง และจำนวน ×N (ถ้าเกิน 1 ชิ้นจะเป็นตัวสีแดง) |
| 2 | **ไม่ยกกล่องขึ้นรถผิดคัน** | โหมดตรวจเช็คขึ้นรถ: ถูกคัน = จอเขียว / ผิดคัน = จอแดงกระพริบ + ไซเรน + เสียงพูดเตือน |
| 3 | **ส่งมอบขนส่งมีหลักฐาน** | ตัดรอบส่งมอบ เทียบยอดกับคนขับ ถ่ายรูปท้ายรถ แล้วส่งสรุปเข้า LINE |
| 4 | **ไม่ต้องติดตั้ง ใช้ได้ทุกอุปกรณ์** | ใช้กล้องหลังมือถือ / ปืนยิง USB-Bluetooth / ถ่ายรูป / พิมพ์เลข |
| 5 | **สินค้าใหญ่เห็นจากระยะไกล** | พิมพ์ป้าย Big Tag ขนาด A5 ตัวอักษรใหญ่ แปะข้างกล่อง |

## 🚀 เริ่มต้นใช้งาน

1. เปิดลิงก์ด้วย **Safari** (iPhone) หรือ **Chrome** (Android)
   - ถ้ากดลิงก์จากแชท LINE แล้วไปเปิดในเบราว์เซอร์ของ LINE ให้กด ⋯ → "เปิดในเบราว์เซอร์" ก่อน เพราะเบราว์เซอร์ของ LINE ใช้กล้องไม่ได้
2. เพิ่มไอคอนไว้หน้าจอเหมือนแอป
   - **iPhone:** ปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม"
   - **Android:** เมนู ⋮ → "เพิ่มลงในหน้าจอหลัก"
3. ครั้งแรกที่กด "เริ่มกล้อง" ให้กด **อนุญาต** ให้ใช้กล้อง
4. แตะหน้าจอ 1 ครั้งก่อนเริ่มงาน เสียงเตือนจึงจะดังได้ (iPhone ต้องปิดโหมดเงียบด้วย)

## 🗓️ ขั้นตอนการทำงานประจำวัน

```
1 โหลดไฟล์ออเดอร์  →  2 สแกนแพ็ค  →  3 เช็คขึ้นรถ  →  4 ส่งมอบขนส่ง  →  5 สรุปยอดส่ง LINE
```

### ขั้นที่ 1: โหลดไฟล์ออเดอร์ (ทุกเช้า / ทุกรอบ)

> บาร์โค้ดและ QR บนใบปะหน้ามีแค่ **เลขพัสดุ** ไม่มีชื่อสินค้าและที่อยู่ (ตาม PDPA) ต้องโหลดไฟล์ออเดอร์ก่อน สินค้า/สี/จำนวนจึงจะขึ้นอัตโนมัติ

**ฝ่ายออฟฟิศ**
1. หลังกดจัดส่งในทุกแพลตฟอร์ม ให้ export ไฟล์คำสั่งซื้อ **รอบเดียวกับกล่องที่จะแพ็ค**
2. ส่งไฟล์เข้ากลุ่ม LINE ของคลัง

**คนงานแต่ละเครื่อง**
1. บันทึกไฟล์จาก LINE ลงเครื่อง (iPhone: บันทึกไปที่แอป "ไฟล์")
2. แท็บ **📥 ไฟล์ออเดอร์** → **➕ เลือกไฟล์ Excel/CSV** (เลือกหลายไฟล์พร้อมกันได้)
3. ตรวจผลที่กล่องสีเขียว เช่น `✅ SPX10.10.26_2.xlsx: 21 ออเดอร์ (SPX 21)`

**ระบบจับคอลัมน์อัตโนมัติ**
- รองรับหัวคอลัมน์ภาษาไทย/อังกฤษของ Shopee, TikTok, Lazada และไฟล์ที่มีหัวรายงานอยู่ด้านบน
- อ่านคอลัมน์ "ข้อมูลสินค้า / product_info" ของ Shopee ที่รวมหลายสินค้าไว้ในช่องเดียวได้
- ถ้าเป็น **ไฟล์รูปแบบใหม่** ที่ระบบหาคอลัมน์ไม่ครบ จะเปิดหน้าต่าง **🧩 เลือกคอลัมน์** ให้ชี้ครั้งเดียว แล้ว **จำไว้** วันถัดไปนำเข้าเองอัตโนมัติ
- ทุกรหัสในแถว (เลขพัสดุ, DHL ID, Ref ID, เลขออเดอร์) ใช้สแกนหาออเดอร์ได้หมด

**ถ้าไฟล์มาช้า:** สแกนแพ็คไปก่อนได้ พอโหลดไฟล์ทีหลัง ระบบจะ **เติมชื่อสินค้าให้กล่องที่สแกนไปแล้ว** อัตโนมัติ

### ขั้นที่ 2: สแกนแพ็คสินค้า

| วิธีสแกน | ทำอย่างไร | เหมาะกับ |
|---|---|---|
| 📷 กล้องสด | กด ▶️ เริ่มกล้อง → จ่อบาร์โค้ดให้อยู่ในกรอบสีเขียว | งานปกติด้วยมือถือ |
| 🔫 ปืนยิง USB/Bluetooth | ยิงได้ทันทีทุกหน้าจอ ไม่ต้องคลิกช่องพิมพ์ | โต๊ะแพ็คที่มีโน้ตบุ๊ก |
| 📸 ถ่ายรูป | ถ่ายใบปะหน้า ระบบอ่านบาร์โค้ด ถ้าไม่เจอจะอ่านตัวอักษร (OCR) | บาร์โค้ดยับ / สะท้อนแสง |
| ⌨️ พิมพ์เลข | พิมพ์เลขพัสดุหรือเลขออเดอร์ แล้วกด "ตกลง" | บาร์โค้ดเสียหายทั้งหมด |

**อ่านหน้าจอผลลัพธ์**
- **แถบสีด้านบน** = ขนส่ง (SPX ส้ม / Flash เหลือง / J&T แดง / LEX น้ำเงิน / DHL เหลือง / BEST แดงเข้ม)
- **✓ พบในไฟล์ออเดอร์** (กรอบเขียว) = ข้อมูลครบ / **⚠ ไม่พบในไฟล์** (กรอบส้ม) = ตรวจใบปะหน้าด้วยตา
- **ชื่อสินค้าตัวใหญ่ + ป้ายสี + จำนวน ×N**: ตรวจของในกล่องให้ตรงทุกข้อ
- **💬 ลูกค้าแจ้ง** = หมายเหตุจากผู้ซื้อ

**หลังตรวจของครบ:** กด **✅ ยืนยันแพ็ค** หรือสแกนกล่องถัดไปได้เลย ระบบจะยืนยันกล่องก่อนหน้าให้เอง

**เสียงเตือน**
- 🔔 บี๊บสั้น 1 ครั้ง = พบในไฟล์ ปกติ
- 🔔🔔 บี๊บต่ำ 2 ครั้ง = ไม่พบในไฟล์
- 🟧 จอส้ม "สแกนซ้ำ!" = กล่องนี้แพ็คไปแล้ว ระบบไม่นับเพิ่ม
- ⚠️ สแกน 3 กล่องติดกันไม่พบในไฟล์ = ไฟล์ที่โหลดไว้อาจเป็นรอบเก่า ให้โหลดไฟล์ล่าสุด

### ขั้นที่ 3: ตรวจเช็คขึ้นรถ

> กฎข้อเดียว: **สแกนก่อนยกทุกกล่อง**

1. แท็บ **📷 สแกน** → กด **🚚 ตรวจเช็คขึ้นรถ**
2. เลือกขนส่งของรถที่กำลังโหลด
3. สแกนทีละกล่อง แล้วดูสีเต็มจอ

| หน้าจอ | ความหมาย | ต้องทำ |
|---|---|---|
| 🟩 **ถูกต้อง! ยกขึ้นรถได้** | ตรงคัน | ยกขึ้นรถ |
| 🟥 **ผิดคัน!** + ไซเรน | กล่องของขนส่งอื่น | **ห้ามยก** วางแยกไว้ แล้วแตะจอเพื่อรับทราบ |
| 🟧 **ยังไม่ได้สแกนแพ็ค** | กล่องนี้ยังไม่ผ่านการแพ็ค | นำกลับไปสแกนแพ็คก่อน |
| 🟧 **ไม่ทราบขนส่ง** | ระบบบอกไม่ได้ว่าเป็นขนส่งไหน | ดูใบปะหน้า ถ้าตรงคันกด "✔ ใช่" ระบบจะ **จำ** ไว้ใช้ครั้งต่อไป |
| 🟧 **สแกนขึ้นรถไปแล้ว / ส่งมอบไปแล้ว** | นับไปแล้ว | ระวังกล่องซ้ำ |

ดูตัวนับ "ขึ้นรถแล้ว / แพ็คแล้ว" ถ้ายังไม่เท่ากัน ให้กด **📋 ดูกล่องที่ยังไม่ขึ้นรถ**

### ขั้นที่ 4: ส่งมอบขนส่ง

1. แท็บ **🚚 ส่งมอบ** → เลือกขนส่งที่มารับ
2. ดูตัวเลข 3 ช่อง: **แพ็คแล้ว / สแกนขึ้นรถแล้ว / ค้าง**
3. ใส่ **ยอดที่คนขับนับรับจริง** ระบบจะบอกว่ายอดตรงหรือต่างกันกี่กล่อง
4. ใส่ทะเบียนรถ ชื่อ/เบอร์คนขับ และถ่ายรูปท้ายรถ (รูปจะมีวันเวลาประทับให้)
5. กด **💾 ตัดรอบส่งมอบ & ส่งสรุปเข้า LINE**

กล่องที่ยังไม่ได้สแกนขึ้นรถจะ **ค้างไปรอบถัดไป** และขึ้นรายชื่อในข้อความ LINE ด้วย

### ขั้นที่ 5: สรุปยอดและรายงาน

แท็บ **📊 สรุปยอด** (ดูย้อนหลังได้ 60 วัน)
- ยอดกล่อง/ชิ้น แยก Shopee / Lazada / TikTok / อื่นๆ
- แยกตามขนส่ง (แพ็ค / ขึ้นรถ / ส่งมอบ / ค้าง)
- สินค้าที่แพ็คมากที่สุด 10 อันดับ
- ออเดอร์ในไฟล์ที่ยังไม่ได้แพ็ค (ใช้เช็คก่อนเลิกงาน)
- ปุ่ม **📤 ส่ง LINE**, **⬇️ ดาวน์โหลด CSV** (เปิดใน Excel ได้ ภาษาไทยไม่เพี้ยน), **📋 คัดลอกข้อความ**

## 🚚 การระบุขนส่งจากเลขพัสดุ

ระบบใช้ข้อมูลจากไฟล์ออเดอร์ก่อนเสมอ ถ้าไม่มีในไฟล์จะดูจากรูปแบบเลขพัสดุ

| ขนส่ง | รูปแบบเลขพัสดุ (ตัวอย่าง) |
|---|---|
| SPX Express | `TH` + ตัวเลข 12–14 หลัก (+ ตัวอักษรท้าย 1 ตัว) เช่น `TH2659775850320`, `TH261685034517U` |
| Flash Express | `TH` + ตัวเลขผสมตัวอักษร |
| J&T Express | ตัวเลข 12 หลักขึ้นต้นด้วย 6 หรือ 8 / `JT…` |
| Kerry Express | `KEX…`, `KER…` |
| Lazada (LEX) | `LEX…`, `LX…` |
| DHL eCommerce | `TDZ…` / ตัวเลข 16 หลักขึ้นต้นด้วย `71` เช่น `7127106028255256` |
| BEST Express | `66` + ตัวเลข 12 หลัก เช่น `66857232447045` |
| ไปรษณีย์ไทย | ตัวอักษร 2 ตัว + ตัวเลข 9 หลัก + `TH` |

เลขรูปแบบอื่นที่ผู้ใช้เคยยืนยันขนส่งไว้ ระบบจะจำและใช้ครั้งต่อไปอัตโนมัติ

## ⚠️ ข้อจำกัดและข้อควรระวัง

- **ข้อมูลแยกกันในแต่ละเครื่อง:** กล่องที่แพ็คด้วยเครื่อง A จะตรวจขึ้นรถด้วยเครื่อง B ไม่ได้ ให้ใช้เครื่องเดียวกันตั้งแต่แพ็คจนส่งมอบ หรือแบ่งเครื่องตามขนส่ง
- **อย่าล้างข้อมูลเว็บไซต์ในเบราว์เซอร์:** จะทำให้ยอดในเครื่องหายทั้งหมด ควรดาวน์โหลด CSV เก็บไว้ทุกสิ้นวัน
- **ระยะเวลาเก็บข้อมูล:** ประวัติเก็บ 60 วัน รูปส่งมอบเก็บ 7 วัน
- **ต้องใช้อินเทอร์เน็ตตอนเปิดครั้งแรก:** เพื่อโหลดตัวอ่านบาร์โค้ด หลังจากนั้นเน็ตหลุดก็ยังสแกนได้
- **กล้องสดต้องเปิดผ่าน HTTPS** (GitHub Pages เป็น HTTPS อยู่แล้ว)
- **ข้อมูลลูกค้า (PDPA):** ไฟล์ออเดอร์มีชื่อและที่อยู่ลูกค้า ส่งเฉพาะในกลุ่ม LINE พนักงานคลัง **ห้ามอัปโหลดไฟล์ออเดอร์ขึ้น GitHub** และลบไฟล์เก่าในมือถือเมื่อส่งของครบแล้ว
